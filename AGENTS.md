# Project Rules

## Frontend Build Artifacts

- `src/main/resources/static/` is generated by the Vue production build and must not be tracked by Git.
- The Docker multi-stage build runs the frontend build and copies its output into `src/main/resources/static/` before packaging the application.
- Do not add generated files under `src/main/resources/static/` to commits. For a non-Docker local Spring Boot run, generate them first with `cd vue-code; npm run build:spring`.
